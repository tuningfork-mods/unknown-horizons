Unknown Horizons — TuningFork maintenance build
==============================================
The open-source Anno-style city builder, kept alive:
bug fixes, backlog cleanup, and builds that run.

To play
-------
1. Extract this archive anywhere you like.
2. Run "UnknownHorizons.sh" (double-click it, or run it from a terminal).

That's it — no installation, nothing is copied onto your system.

Requirements
------------
Linux x86_64 with Python 3.12, PyYAML, and standard graphics/audio
libraries (SDL2, OpenGL, OpenAL). On Debian/Ubuntu:

  sudo apt install python3.12 python3-yaml libsdl2-2.0-0 libopenal1

Saves, settings and screenshots live in your home directory
(~/.config/unknown-horizons and ~/.local/share/unknown-horizons).

This build is free, as always. Source code: github.com/tuningfork-mods/unknown-horizons

Tips welcome at ko-fi.com/tuningfork.
